# Daily Standup 实景操作手册入口

本页是不含企业工单正文的产品文档索引。真实截图与报告保存在 Git 忽略的本地目录，
不随代码提交或推送。当前功能说明以
[项目与报告指南](../../openspec/docs/current-baseline/project-reporting.md)为准。

## 中文图文手册

本机打开 `docs/_build/chiplet-standup-live-20261107/manual.html`。
同目录 `README.md` 说明文件组织，`diagrams/` 提供可缩放流程图和架构图，
`reports/` 包含实际下载的两份 HTML 及恢复日 Markdown，
`evidence/verification.json` 记录原始文件和继承校验。

交付范围：

1. 产品对象与职责：连接、scope、项目、阶段、模板版本和报告系列。
2. 真实 Jira 的只读连接、企业 CA、scope/UI 成员集合核对。
3. 第一天采集、生成草稿、精简 note、富文本颜色、保存与显式定稿。
4. 中间一天停会，不生成空报告、不推进编辑基线。
5. 第三天再次真实采集，继承前次定稿内容，再编辑、定稿和导出。
6. 错误处理、操作演示脚本、API 和文件契约，以及尚未验证的边界。

## 实景证据边界

2026-11-07完成了用户授权的限定真实 Jira 演示：
16条工单，两次完整来源采集，两份人工编辑后的定稿，12个原始文件校验。
第一天16份note的正文、颜色、编辑来源和源状态完整带入恢复日。
最终32份note只属于两个会议日，中间停会日没有生成note。

会议日期采用2026-11-04、11-05停会、11-06恢复；两次数据都实际采集于11-07。
它不是历史来源还原，也不是新机器安装或生产部署资格。

实际采用原生capture API加产品`saved_capture / manual_only`路径。
没有将真实来源伪装为synthetic运行，没有调用运行时真实AI模型。
实时`#ID`成功补全没有在此实例启用；手工AR文本保留在Updates，不自动变为结构化AR。
两种限制和摘要覆盖率文案均在手册中明确说明。

## 运行与安全

演示浏览器和本地服务已正常关闭，HTML手册及成果可直接离线阅读。
需要重新启动保留实例时，遵循手册中的唯一数据根、端口和stop-file步骤；
不要重复执行已经完成的采集命令，也不要覆盖原演示记录。

公司PAT、浏览器cookie和生产数据库不在文档包中。真实业务截图、姓名和报告内容
仍属于企业数据，不得因文档没有凭据就视为可公开发布。

本次文档/实例验证不关闭更广泛的真实provider、真实模型、Outlook、
调度或生产部署门槛；其状态仍见唯一OpenSpec任务清单。
