# Codex Project Skills

Codex reads `.agents/skills/` (from the working directory up to the repository root),
`~/.agents/skills/` and `~/.codex/skills/`; Copilot reads this directory after `.github/skills/`.
The layout rules for all three tools are in [`.github/skills/README.md`](../../.github/skills/README.md).

## Codex-only role adapters

`architect-planner-reviewer`, `dashboard-debugger`, `implementation-engineer`,
`validation-engineer` and `lsheng2-agent-router` let Codex take the roles defined in
`.github/agents/*.agent.md` and `.github/custom-agents.md`, which stay the source of truth. Copilot
uses those custom agents directly, so `.github/copilot/settings.json` turns these adapters off for
Copilot. Do not duplicate role definitions here.

## Other entries

- `r2-change-loop`: executes an approved R2 OpenSpec change (`AI_CONTRACT.md` §1); mirrored byte
  for byte in `.claude/skills/`.
- `web-design-guidelines`: upstream v1.1.0 installed with
  `npx skills add https://github.com/vercel-labs/agent-skills/tree/<release-tag>/skills/web-design-guidelines -a codex -y`;
  the tag and content hash are recorded in `skills-lock.json`. The rules are bundled in
  `references/command.md` and are not fetched at review time. Upgrade by rerunning the command with
  a newer release tag instead of following the upstream maintainer steps in its `SKILL.md`.
- `openspec-*` and `.openspec-target`: generated by `openspec update`; do not edit by hand.
- `drawio`: points Codex at `.github/skills/drawio/`.
