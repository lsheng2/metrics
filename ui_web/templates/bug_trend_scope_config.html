Name, JQL, bug type values, timezone and bucket granularity.

Enable Scope requires

Open status, severity field, critical/high values, medium/low values, and fixed or closed status.

Provider metadata uses

Jira project/type context for candidate lookup. IP and Project label are display/binding hints. It is advisory unless selected in Query Builder.

Dashboard/AI needs

Provider binding, successful sync, fresh calculation and evidence-capable chart contract.
