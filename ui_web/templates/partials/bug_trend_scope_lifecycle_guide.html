Readiness matrix

What each capability requires

Capability Requires If missing
Create draft Name, provider query, bug type, bucket granularity, timezone format Scope cannot be saved.
Deploy to Dashboard selector Draft validation plus open status, fixed/closed status, severity field, critical/high and medium/low values Scope stays archived and cannot participate in normal Dashboard selection.
Sync facts Deployed scope, provider credentials, valid query permissions Data Health reports sync/cache blocker.
Calculate buckets and evidence Synced source facts and coverage window Charts show no current calculation or stale coverage.
Workbench evidence Fresh calculation run and chart evidence contract Ticket list is unavailable or selection is summary-only.
AI Assistant Grafana charts Provider binding, profile readiness, fresh facts/calculation and AI sidecar readiness AI can explain blockers but should not publish a chart as ready.
